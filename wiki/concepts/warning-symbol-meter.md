# Warning symbols (clause 12)

IEC 387 §12 is a short clause: **any reference to a separate document shall be
marked on the name-plate by the symbol △ (a triangle).** It is the meter
equivalent of the general "see the accompanying documents" warning sign, directing
the user to a separate instruction sheet or supplementary document where the
name-plate alone cannot carry all the information.

This warning triangle is distinct from the **excess-energy** triangle of §9 b
([[excess-energy-meter]], [[tariff-device-symbols]]), which marks a power
threshold rather than a documentation reference — context (a numeric power value
beside it vs. none) disambiguates them. The warning symbol is placed on the
[[meter-name-plate-and-dial|name-plate]].

See also: [[iec-387]] §12.
