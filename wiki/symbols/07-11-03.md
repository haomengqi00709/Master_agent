# 07-11-03 — Button-operated switch: same contact set operated by turning (locking) or pushing (spring return), shown with terminals

## Description
Button-operated switch in which the same set of contacts may be operated in two different ways; either by turning (with locking) or pushing (with spring return), shown with terminals

## Names
- **EN:** Button-operated switch: same contact set operated by turning (locking) or pushing (spring return), shown with terminals
- **FR:** Commutateur à commande par un bouton actionnant un même ensemble de contacts, soit par rotation, soit par pression, figuré avec ses bornes
