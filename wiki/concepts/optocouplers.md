# Optocouplers — Ex repair

Opto-isolators in intrinsically safe circuits; replace only with a component of the same or directly equivalent type and certification.

In [[iec-79-19]], repair/overhaul/reclamation of this component is specified per type of protection:

- **[[type-of-protection-i|"i" — intrinsic safety]]** (clause 4): Only components of the same or directly equivalent type and certification shall be used as replacements (4.2.9).
