# Definite time-delay over-current release

An [[over-current-release]] which operates after a definite interval of time which is independent of the value of the over-current ([[iec-56]] 3.104.20, IEV 441-16-34). On the current in the release exceeding its predetermined setting, a fixed, pre-set time delay elapses before the release actuates the [[operating-mechanism]] to open the [[circuit-breaker]]; raising the fault current does not shorten that interval (unlike an inverse time-delay over-current release, where operating time falls as current rises). The defined delay supports time-graded discrimination between series protective devices. It contrasts with the [[instantaneous-release]], which has no intentional delay. The opening time is measured with any such integral time-delay device set to its minimum ([[iec-56]] 3.105.32).
