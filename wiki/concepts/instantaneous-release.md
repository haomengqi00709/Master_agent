# Instantaneous release

A release which operates without any intentional time delay ([[iec-56]] 3.104.17, IEV 441-16-32). Once its initiating quantity reaches the set value, the release acts at once to trip the [[operating-mechanism]] and open the [[circuit-breaker]], the only delay being the inherent response time of the mechanism. The term qualifies the time characteristic rather than the actuating quantity, so an [[over-current-release]] without intentional delay is an instantaneous over-current release. It contrasts with the [[definite-time-delay-over-current-release]] and inverse time-delay types, which deliberately postpone tripping. A [[making-current-release]] behaves instantaneously during a closing operation.
