# Push-button

Defined in **IEC 73 §2.2** as *"part of an electrical device, consisting of a
button which must be pressed to effect an operation"* (in accordance with I.E.V.
definition 15-15-140). With the [[indicator-light]] it is the second object to
which [[iec-73]] assigns a colour code — here the colour is a **surface colour as
seen in incident white light**, not transmitted light.

For push-buttons seven colours are available (§3.1.2): **RED, YELLOW, GREEN, BLUE,
BLACK, WHITE and GREY** — three more than for indicator lights, because BLACK,
WHITE and GREY are the *neutral* colours used where no specific function meaning
is to be conveyed. The colour is chosen with regard to the **operation initiated
when the button is pressed** ([[choice-of-colours]]). The function-to-colour rules
form clause 5 and are summarised in Table II ([[push-button-colour-table]]):
- RED is reserved for STOP/OFF/emergency — [[push-button-stop-emergency]] (§5.1);
- GREEN is preferred for START/ON, neutral colours permitted — [[push-button-start-on]] (§5.2);
- alternating START/STOP and inching buttons use neutral (or GREEN) colours — [[push-button-start-stop-combined]] (§5.3);
- RESET buttons are BLUE or neutral — [[push-button-reset]] (§5.4).

A push-button whose actuator is itself lit is an [[illuminated-push-button]]
(§2.3), for which both the light colour (Table I) and the button function (Table
II) apply. The corresponding 60617 graphic is the non-locking push-button switch
[[07-07-02]].
