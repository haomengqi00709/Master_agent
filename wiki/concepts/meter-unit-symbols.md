# Symbols of principal units used for meters (clause 5)

IEC 387 §5 and **Table 2** list the letter symbols for the principal electrical
and time units that appear on meter name-plates and dials (items 5.1–5.15):

| § | Unit | Symbol |
|---|------|--------|
| 5.1 | Ampere | A |
| 5.2 | Volt | V |
| 5.3 | Watt | W |
| 5.4 | Watt-hour | Wh |
| 5.5 | Var | var |
| 5.6 | Var-hour | varh |
| 5.7 | Volt-ampere | VA |
| 5.8 | Volt-ampere-hour | VAh |
| 5.9 | Hertz | Hz |
| 5.10 | Volt squared hour | V²h |
| 5.11 | Ampere squared hour | A²h |
| 5.12 | Hour | h |
| 5.13 | Minute | min |
| 5.14 | Second | s |
| 5.15 | Degrees Celsius | °C |

These unit symbols are the building blocks for [[measured-quantity-marking]]
(§6), which requires the unit of the nominal measured quantity to be marked
conspicuously on the dial (commonly with the SI prefix k, e.g. kWh, kvarh, kVAh).
The energy units correspond to the meter types defined in clause 3 —
Wh/[[watt-hour-meter-def]], varh/[[var-hour-meter-def]],
VAh/[[volt-ampere-hour-meter-def]] — while V²h and A²h support specialised
squared-quantity meters.

See also: [[measured-quantity-marking]] · [[iec-387]] §5.
