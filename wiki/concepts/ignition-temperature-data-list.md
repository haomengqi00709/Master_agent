# Established ignition temperatures (reference data)

The reference table of ignition temperatures determined by the [[iec-79-4]]
method. **Amended (Amd.):** this list is published by the first supplement
[[iec-79-4a|79-4A (1970)]]; the base standard itself gives only the three Table I
calibration substances.

**Calibration substances — Table I, [[iec-79-4]] §4.2** (purity ≥ 99.9 %, used to
verify a [[ignition-test-furnace|furnace]] against the §7 tolerances):

| Product | Ignition temperature (°C) |
|---------|---------------------------|
| n-Heptane | 220 |
| Ethylene | 435 |
| Benzene | 560 |

**Established list — [[iec-79-4a|amendment 79-4A]].** Inclusion rule (Note 1):
values measured by the IEC 79-4 method in **at least two countries**, retained
only within the **5 %** [[repeatability-reproducibility|reproducibility]] limit of
§7.2:

| Substance | Chemical formula | Ignition temp. (°C) |
|-----------|------------------|---------------------|
| Acetic anhydride | (CH₃CO)₂O | 334 |
| Acetone | (CH₃)₂CO | 535 |
| Benzene | C₆H₆ | 560* |
| Buta-1,3-diene | CH₂:CH·CH:CH₂ | 430 |
| iso-Butanol | (CH₃)₂CH·CH₂OH | 408 |
| Carbon disulphide | CS₂ | 102 |
| Chlorobenzene | C₆H₅Cl | 637 |
| Cyclohexane | C₆H₁₂ | 259 |
| Cyclohexanone | C₆H₁₀O | 419 |
| 1,4-Dioxan | C₄H₈O₂ | 379 |
| Ethylbenzene | C₆H₅·C₂H₅ | 431 |
| n-Heptane | C₇H₁₆ | 215* |
| n-Hexane | C₆H₁₄ | 233 |
| Dimethoxymethane | CH₂(OCH₃)₂ | 236 |
| Naphthalene | C₁₀H₈ | 528 |
| n-Nonane | C₉H₂₀ | 205 |
| 2,2,4-Trimethylpentane (iso-octane) | CH₃CH(CH₃)CH₂C(CH₃)₃ | 411 |
| n-Tetradecane | CH₃(CH₂)₁₂CH₃ | 201 |
| Tetrahydrofuran | C₄H₈O | 224 |
| Toluene | C₆H₅·CH₃ | 535 |
| Trichlorosilane | HSiCl₃ | 230 |
| Vinyl acetate | CH₃·COO·CH:CH₂ | 385 |
| p-Xylene | C₆H₄(CH₃)₂ | 528 |

\* The amendment list reports benzene 360 °C in OCR and n-heptane 215 °C, which
differ from the §4.2 Table I calibration values (benzene 560 °C, n-heptane
220 °C). The "360" is an OCR mis-read of **560**; the 215 vs 220 difference is a
genuine inter-source/edition variation within the test's stated tolerance.

These numbers feed directly into the [[temperature-classes-t1-t6|temperature
classes T1–T6]]: e.g. carbon disulphide (102 °C) is so low it forces a high class
(T5/T6 surface limits of 100/85 °C), while chlorobenzene (637 °C) tolerates T1.
**Amended (Amd.):** Note 2 of 79-4A warns impurity/ageing can shift a value
appreciably — trichlorosilane falls from 230 °C to 185 °C after ageing — see
[[factors-affecting-ignition-temperature]].
