# 13-05-09 — Analogue operand input (X-input shown)

![13-05-09](../assets/60617-13/p10.png)
<sub>This symbol appears on Publication No.617-13.pdf, printed p.16 (full page shown).</sub>

**Standard:** [[60617-13]] · **Section:** [[60617-13-05-qualifying-symbols-indicating-the]]

## Description
This input represents an operand on which one or more analogue functions are performed. For analogue operands the letters X and Y should be used.

## Names
- **EN:** Analogue operand input (X-input shown)
- **FR:** Entrée opérande analogique (entrée X figurée)

## Notes
- May be shown without the subsidiary-connection symbol (13-04-05) if no confusion is likely.
- A + or − may be added as a suffix to indicate polarity.
