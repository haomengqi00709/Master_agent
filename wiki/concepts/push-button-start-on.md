# Push-button — START / ON (GREEN preferred)

**IEC 73 §5.2.** The **preferred** colour of START buttons or ON buttons — those
which **cause the closing of switching devices** — is **GREEN**, but the neutral
colours **BLACK, WHITE or GREY are permitted**. So unlike the absolute RED rule
for stop functions ([[push-button-stop-emergency]] §5.1), GREEN here is a
recommendation rather than a reservation: a start button *should* be green, but a
neutral button is acceptable. (Correspondingly, GREEN is *not* mandatory for
start, and the START-button colour must avoid RED.)

In Table II ([[push-button-colour-table]]) GREEN means **START or ON**, with
typical applications: general start; start one or more motors; start a part of a
machine; close a switching device. For the **relative positioning** of start/stop
buttons, the standard refers to **IEC 447** (standard directions of movement for
actuators — §5.2 note). The light counterpart is [[indicator-light-green]]
(safety / machine ready to be started). See also
[[push-button-start-stop-combined]] (§5.3), where a single button alternates
between start and stop and therefore must be neutral (neither RED nor GREEN), and
inching buttons that may be GREEN but preferably BLACK.
