# IP first numeral 0 — non-protected

The lowest level of the [[ip-code-structure|first characteristic numeral]]
([[iec-529]], 1st ed. Table I; 2nd ed. clause 5). A first numeral **0** means the
enclosure provides **no special protection** of persons against access to
hazardous parts and **no protection** of equipment against ingress of solid
foreign objects. There is no object-size limit and no access barrier.

Because nothing is claimed, **no test is required** for first numeral 0
([[iec-529]] 1st ed. §7: "For first characteristic numeral 0, no test is
required"). An enclosure designated e.g. `IP0X` makes no first-numeral claim at
all. As with every level, a higher numeral automatically subsumes 0; 0 is the
baseline that any enclosure trivially meets.

This is the solid-object/access counterpart of [[ip-second-numeral-0]] (no water
protection); a fully unrated enclosure is `IP00`.
