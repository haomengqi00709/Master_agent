# Kind-of-item letter codes (Table I)

**Table I of IEC 750** assigns a single **letter (A…X)** to each *class of item*,
so that the [[item-identification-block|Block 3 identification]] of an item can name
*what kind of thing it is* before its serial number ([[iec-750]] Table I, §5). The
letter is the `K` in `-K1`, the `R` in `-R2`. The classes are functional groupings
("relays and contactors", "resistors") rather than exact component types, so a wide
range of real components map onto each letter; the examples in the table are
illustrative, not exhaustive.

| Letter | Kind of item (class) | Typical examples (Table I) |
|--------|----------------------|----------------------------|
| **A** | Assemblies, subassemblies | amplifier (subassembly), laser, maser; any grouped subassembly `-A1`, `-A2` |
| **B** | Transducers — non-electrical → electrical or vice-versa | sensing/measuring transducers, microphone, loudspeaker, pick-up, thermocouple-as-sensor, detector |
| **C** | Capacitors | capacitor `-C1` |
| **D** | Binary/digital elements, delay devices, storage | bistable, monostable, register, magnetic-core store, delay line |
| **E** | Miscellaneous (items not covered by other letters) | lighting/heating items, and anything with no specific letter |
| **F** | Protective devices | fuse, over-voltage protective device, lightning arrester, over-current release |
| **G** | Generators, supplies | generator, battery, oscillator, rotating/static supply source |
| **H** | Signalling devices | optical and acoustic indicators, indicator light, buzzer, bell, lamp (signalling) |
| **K** | Relays and contactors | relay, contactor `-K1` |
| **L** | Inductors | inductor, coil, winding, reactor |
| **M** | Motors | motor `-M1` |
| **N** | (analogue elements) | analogue/operational amplifier, analogue computing element |
| **P** | Measuring instruments, test equipment | indicating/recording/integrating instruments, meters, clocks, counters |
| **Q** | Power switching devices (power circuits) | circuit-breaker `-Q1`, isolator, power switch, motor-protection switch |
| **R** | Resistors | resistor `-R1`, variable resistor, potentiometer, shunt, thermistor |
| **S** | Switches, selectors (control/signal circuits) | control switch, pushbutton `-S1`, limit switch, selector |
| **T** | Transformers | voltage transformer, current transformer `-T1` |
| **U** | Modulators, changers, converters | discriminator, demodulator, frequency changer, coder, inverter, converter, telegraph translator |
| **V** | Tubes, semiconductors | thermionic tube, gas-discharge tube, diode, transistor, thyristor `-V1` |
| **W** | Transmission paths, waveguides, aerials | conductor, cable, busbar, waveguide, directional coupler, dipole, parabolic aerial |
| **X** | Terminals, plugs, sockets | terminal board `-X1`, plug, socket, connector, test jack |
| **Y** | Electrically operated mechanical devices | electromagnetic brake, clutch, pneumatic valve, electrically-operated actuator `-Y1` |
| **Z** | Terminations, hybrid transformers, filters, equalizers, limiters | balancing/cable network, filter, equalizer, limiter, crystal filter |

These letters are the **same reference letters** the [[60617-1|general index of
IEC 60617-1]] attaches to each graphical symbol, so a reader can step from symbol →
kind-letter → IEC 750 designation. They appear directly in IEC 750's own figures:
`-A1`/`-A2` (subassemblies), `-S1` (pushbutton), `-Q1`/`-Q2` (circuit-breaker and
main-contact assembly), `-R2` (resistor), `-C1` (capacitor), `-K1`…`-K6` (relays),
`-V1`/`-V2` (semiconductors), `-M1` (motor), `-H3` (signalling), `-B1` (transducer),
`-Y1`/`-Y3` (mechanical devices).

**Note on OCR:** Table I (source pp. 27–) is rendered as a rotated multi-column
scan and is only partially legible in the OCR; the letter→class mapping above is
reconstructed from the legible rows (T, U, V, W, X, Y on source p. 16, plus every
letter used in Figures 3–11) and is the standard IEC 750:1983 set later carried
into IEC 61346-2 / 81346-2.
