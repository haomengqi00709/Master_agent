# Illuminated push-button types (Table III)

**IEC 73 §6.1, Table III.** Referring to the colours shown by the button, three
types of [[illuminated-push-button]] are distinguished by what colour appears when
**not lighted** versus **lighted**:

| Type | Not lighted | Lighted |
|------|-------------|---------|
| **a** | No specific colour (neutral) | Any one colour |
| **b** | No specific colour (neutral) | Different colours (separate lamps for each colour) |
| **c** | Different colours | Different colours |

So a type-**a** button is neutral when dark and shows a single coded colour when
lit; type-**b** is neutral when dark but can show **several** colours via separate
lamps; type-**c** is coloured both when dark and when lit. A note clarifies the
boundary of the definition: **lamps used as indicator lights but designed to be
pushed for testing the lamp are *not* illuminated push-buttons** (a lamp-test push
does not make an [[indicator-light]] into a button).

The type matters for operation: types **a** and **b** follow the two
[[illuminated-push-button-modes-of-use]] of §6.3 (indication, confirmation), while
type **c** may be used in **both** modes but each application must be carefully
examined to prevent confusion (§6.3.2). Whatever the type, the lighted colour must
obey Table I ([[indicator-light-red]] … [[indicator-light-white]]) and the button
function must obey Table II ([[push-button-colour-table]]), per the basic
requirement §6.2.
