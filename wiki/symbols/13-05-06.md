# 13-05-06 — Reference output

![13-05-06](../assets/60617-13/p09.png)
<sub>This symbol appears on Publication No.617-13.pdf, printed p.14 (full page shown).</sub>

**Standard:** [[60617-13]] · **Section:** [[60617-13-05-qualifying-symbols-indicating-the]]

## Description
Reference output: an output that is a reference source. The asterisk shall be replaced by the symbol for the reference quantity (U, I, f, φ). If it is not necessary to emphasize that it is a reference input/output, use 13-05-07/13-05-08.
