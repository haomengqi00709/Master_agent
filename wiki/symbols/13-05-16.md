# 13-05-16 — Hold input

![13-05-16](../assets/60617-13/p12.png)
<sub>This symbol appears on Publication No.617-13.pdf, printed p.20 (full page shown).</sub>

**Standard:** [[60617-13]] · **Section:** [[60617-13-05-qualifying-symbols-indicating-the]]

## Description
When this input takes its internal 1-state, the analogue outputs hold their values; in the 0-state it has no effect.

## Names
- **EN:** Hold input
- **FR:** Entrée de maintien
