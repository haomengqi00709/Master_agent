# Cross-correspondence: IEC 617 ↔ legacy IEC Publication 117

From **[[60617-1]]** Section 3. This table maps every **new IEC 617 symbol
number** (`PP-SS-NN`) to the **old IEC Publication 117 number** it replaced (and
its 617 part). IEC 117 was the pre-1983 graphical-symbol series; 617 reorganised
and renumbered it. Use this to resolve a legacy "117-xxx" reference to a modern
617 symbol node.

The standard prints the correspondence **twice** on each spread — the left
column-group sorted by the old 117 number, the right group sorted by the new 617
number — each group having three columns: **N° 617 | Part | N° 117**.

> **Source-image table.** The pages below are the authoritative scanned table
> (re-oriented upright). They are embedded verbatim so the mapping is exact —
> dense number-tables are transcribed unreliably, so for any critical lookup read
> the image. A best-effort machine extraction (~1300 rows via subagents) was also
> produced during ingest and can be written to a JSON dataset on request; it
> should be validated against these images before use.
